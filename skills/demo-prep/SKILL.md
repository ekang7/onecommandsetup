# Demo prep

Write DEMO.md, one page:
1. Problem: one sentence.
2. What I built: three to five bullets.
3. Live demo script: the exact commands or clicks, in order, with expected output.
4. Code walkthrough path: the files and functions to open, in order, with one line each on why.
5. Key decisions and trade-offs: three maximum.
6. Experiment results: the results table and the one-line conclusion.
7. Limitations and next steps.
8. Likely questions with short answers: five to eight.

Then run the demo script once end to end. Fix anything that fails before the demo.
